# Inventarios

Control de existencias: que lo que dice el sistema sea lo que hay, y que lo que se consumió
sea lo que debía consumirse.

## Qué va aquí

- Procedimiento de conteo de inventario (frecuencia, responsables, método).
- Formatos de conteo por tienda y por centro de producción.
- Análisis de **consumo teórico vs. consumo real**.
- Control de mermas, roturas y desperdicio.
- Control de transferencias entre el centro de producción y las tiendas.
- Resultados de conteos por período.

## Lo que se persigue

**La diferencia.** Consumo teórico es lo que la tienda debió gastar según lo que vendió y
según las fichas técnicas. Consumo real es lo que efectivamente gastó, medido por conteo.
La diferencia entre ambos es la señal.

Una diferencia recurrente se explica normalmente por una de estas causas:

| Causa | Dónde se resuelve |
|---|---|
| Gramajes fuera de estándar en producción | [Operaciones — Producción](../../02-operaciones/produccion/) |
| Merma no registrada | Aquí + Producción |
| Conteo mal hecho | Aquí |
| Recepción de mercancía mal verificada | [Compras](../compras/) |
| Transferencias sin registrar | Aquí |
| Fuga | Aquí |

El orden importa: antes de concluir que hay una fuga, hay que descartar las cinco causas
anteriores. La mayoría de las diferencias son de proceso, no de robo, y tratar un problema
de proceso como un problema de honestidad daña al equipo sin resolver nada.

## Frontera con Operaciones

Las fichas técnicas las define Operaciones; el consumo contra esas fichas se mide aquí.
Cuando el análisis apunta a un problema de ejecución en tienda, el hallazgo se comparte con
Omar y la corrección se trabaja del lado operativo.
