# Glosario

Términos y siglas que usamos en el proyecto. Se va llenando sobre la marcha: si en una
reunión aparece una sigla que no todos manejan, va aquí.

| Término | Significado |
|---|---|
| **Abruzzos** | El cliente. Cadena de pizzerías en Venezuela. |
| **Escala** / **Escala Consultores** | La consultora que acompaña el proyecto. Nuestro equipo. |
| **CP** | Centro de producción. Unidad que produce y abastece a las tiendas. |
| **Tienda** | Cada local o punto de venta de Abruzzos. |
| **Gerente de tienda** | Responsable de la operación diaria de un local. |
| **Gerencia de operaciones general** | Cargo interno de Abruzzos que coordina a todas las tiendas. |
| **PM** | Project manager. En este proyecto: Omar y Adalberto. |
| **Plaza** | Ciudad o zona objetivo de expansión (ej. Lechería, Puerto La Cruz). |
| **Apertura** | Doble uso: (1) el proceso diario de abrir una tienda; (2) la inauguración de una tienda nueva. Se aclara en cada documento cuál de los dos. |
| **Hallazgo** | Desviación detectada en una auditoría, con su evidencia y su acción correctiva. |
| **Estándar** | Documento que define cómo debe hacerse algo en todas las tiendas por igual. |
| **SOP / POE** | Procedimiento operativo estándar. El paso a paso de una tarea. |
