# Registro de decisiones

Cada vez que tomemos una decisión que cambie el rumbo de algo — un proceso, una
estructura, un criterio, una herramienta — se deja aquí una nota corta.

No es burocracia: es que dentro de tres meses nadie se acuerda de **por qué** se decidió
algo, y esa es justamente la pregunta que aparece cuando alguien quiere cambiarlo.

## Cómo se agrega una

Nombre del archivo:

```
AAAA-MM-DD-tema-corto.md
```

Contenido (cuatro puntos, breve):

```markdown
# Título de la decisión

**Fecha:** 2026-09-18
**Decide:** Omar / Adalberto / Cristian
**Estado:** vigente | reemplazada por [otra decisión]

## Contexto
Qué situación nos obligó a decidir.

## Decisión
Qué se decidió. En una o dos frases.

## Por qué
El motivo. Y qué alternativa se descartó.

## Consecuencias
Qué cambia a partir de ahora.
```

Una decisión no se borra ni se reescribe. Si cambia, se agrega una nueva que diga que
reemplaza a la anterior, y la anterior se marca como reemplazada.
