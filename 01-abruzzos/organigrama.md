# Organigrama

Cómo está estructurado el equipo de Abruzzo's y quién le responde a quién.

> **Importante:** el organigrama que sigue es el **propuesto** por el
> [Plan Maestro de Operaciones](../02-operaciones/plan-maestro-de-operaciones.md), todavía en
> revisión. Varios de sus cargos no existen hoy. Lo que existe y lo que falta está separado
> más abajo.

## Organigrama propuesto

```
DIRECCIÓN DE OPERACIONES
(Externo · Consultoría — supervisa directamente ambas líneas)
│
├── GERENTE DE OPERACIONES  ·  interno  ·  $1,300/mes
│      │
│      ├── COORDINADOR DE COMPRAS / ABASTECIMIENTO  ·  $700/mes
│      ├── COORDINADOR DE LOGÍSTICA  ·  $700/mes
│      ├── COORDINADOR DE RR. HH.  ·  $700/mes
│      │
│      ├── JEFE DE CDP CARACAS
│      │      └── Cocineros Expertos → Ayudantes de Cocina
│      ├── JEFE DE CDP ORIENTE (Puerto La Cruz)
│      │      └── Cocineros Expertos → Ayudantes de Cocina
│      │
│      └── GERENTES DE TIENDA (x13)
│             └── Sub Gerente → Cajeros / Runners / Cocineros Expertos /
│                  Ayudantes de Cocina / Motorizados
│
└── SUPERVISOR(ES) DE OPERACIONES  ·  externo, campo  ·  2 posiciones
       Reporta exclusivamente a la Dirección de Operaciones
```

### El principio: dos líneas, sin subordinación entre ellas

- **Línea 1 — gestión del día a día.** El Gerente de Operaciones, interno, administra tiendas,
  CDP y las tres coordinaciones.
- **Línea 2 — auditoría en campo.** Los Supervisores de Operaciones, externos, verifican en
  sitio el cumplimiento de los procesos.

Ninguno manda sobre el otro: **ambos reportan a la Dirección de Operaciones.** Colaboran como
pares, comparten indicadores y hallazgos. El objetivo del diseño es que quien audita no
dependa de quien es auditado.

### Relaciones de reporte

| Cargo | Reporta a | Colabora con (sin subordinación) | Naturaleza |
|---|---|---|---|
| Dirección de Operaciones | — (vértice) | — | Externo · Consultoría |
| Gerente de Operaciones | Dirección de Operaciones | Supervisor(es) de Operaciones | Interno |
| Supervisor(es) de Operaciones | Dirección de Operaciones | Gerente de Operaciones | Externo · Campo |
| Coordinadores (Compras, Logística, RR. HH.) | Gerente de Operaciones | Supervisor(es) de Operaciones | Interno |
| Jefes de CDP / Gerentes de Tienda | Gerente de Operaciones | Supervisor(es) de Operaciones | Interno |

## Estructura dentro de cada unidad

**En cada tienda**

```
GERENTE DE TIENDA
└── Sub Gerente
       └── Cajeros / Runners / Cocineros Expertos / Ayudantes de Cocina / Motorizados
```

**En cada CDP**

```
JEFE DE CDP
└── Cocineros Expertos → Ayudantes de Cocina
```

## Qué existe hoy y qué no

| Cargo | ¿Existe hoy? |
|---|---|
| Gerentes de Tienda | Sí |
| Sub Gerentes de Tienda | **Solo en 3 de las 7 tiendas** |
| Jefes de CDP | Sí |
| Jefes de Logística/Compras en los CDP | Sí, pero cada uno negocia y abastece por su cuenta |
| Jefe de Cocina | Sí, pero concentra toda la responsabilidad técnica en una persona por tienda, sin cubrir los 7 días |
| Gerente de Operaciones | _Por confirmar si el cargo ya está ocupado_ |
| Coordinador de Compras | **No existe** |
| Coordinador de Logística | **No existe** (cargo nuevo) |
| Coordinador de RR. HH. | **No existe** — no hay área de RR. HH. |
| Supervisor de Operaciones | **No existe** (figura nueva) |
| Dirección de Operaciones | Figura externa, es la que aporta Escala |

## Dónde encaja Escala

La **Dirección de Operaciones** del organigrama es la figura externa de consultoría en la
cúspide, y es el papel que ocupa Escala en este esquema.

Falta definir por escrito dos cosas:

- [ ] **Quién de Escala ocupa la Dirección de Operaciones** y con qué nombre se comunica a la
      organización. Ojo con la colisión de términos: el plan reserva *"Gerente de
      Operaciones"* para el cargo **interno** de $1,300/mes, así que llamar así a alguien de
      Escala genera confusión directa en la línea de mando.
- [ ] **Dónde encaja Adalberto.** El plan pone Compras, Logística e inventario bajo el Gerente
      de Operaciones (interno) y la auditoría OER bajo el Supervisor de Operaciones (externo),
      pero no dice en qué punto del organigrama entra la auditoría que Adalberto hace desde
      Escala sobre inventarios, compras y caja.
